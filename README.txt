MADHAVAN PORTFOLIO — SUBMISSION NOTES

Files included
- index.html    Home page
- about.html    About page and skills
- projects.html Project concepts page
- contact.html  Contact form demo
- style.css     Responsive styling, CSS Grid, Flexbox, CSS variables, light/dark theme
- script.js     Theme toggle, current year, contact-form mailto behavior

How to run
1. Keep all files in the same folder.
2. Open index.html in a modern browser, or use VS Code + Live Server.
3. Test the nav links, theme toggle, responsive layout, and contact form.

Before submitting
- In script.js, replace your-email@example.com with the email address that should receive contact form messages.
- The project cards are clearly labelled as concepts. Replace them with your actual projects and repository/demo links when available.
- The Google Fonts import requires internet; system fallback fonts will be used offline.

Implementation notes
- Semantic HTML landmarks and skip links are included.
- Layout is mobile-first and uses CSS Grid and Flexbox.
- Theme preference is saved in localStorage when available and follows the system preference on first visit.
- Contact form uses mailto and does not send data to a server.
